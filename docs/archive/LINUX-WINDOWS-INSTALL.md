# Linux / Windows install (archived)

Status: archived, not deleted. macOS is the primary platform for now.
Linux and Windows install paths below are preserved so they can be
restored later. Do not link this file from the apex README until
those platforms are officially supported again.

## Linux

```bash
curl -fsSL https://hongnoul.github.io/gwae/install.sh | bash
```

## Windows

```powershell
irm https://hongnoul.github.io/gwae/install.ps1 | iex
```

Key note for restoration: `⌥` is Option on macOS and Alt on Linux
and Windows. If shortcuts type glyphs instead of dispatching, set
Option to act as Meta in the terminal settings.
